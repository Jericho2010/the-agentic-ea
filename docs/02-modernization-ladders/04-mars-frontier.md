# 2.4 — Mars ladder — frontier / stretch stack

Mars is **stretch ideation**: combine Moon with durable agent harnesses, deep runtime sensing, and knowledge-graph reasoning. Treat as experimental unless you have platform maturity.

## Mars themes

| Theme | Examples / directions |
|---|---|
| Runtime ground truth | eBPF (Cilium), OpenTelemetry traces correlated to PAM interfaces |
| Durable automation | Windmill, Trigger.dev, Kestra-style durable jobs driving EA loops |
| Knowledge graphs | Lakehouse graph tables + semantic reasoning layers (e.g., research systems such as Semantica-class tools where available) |
| Hypermedia explainers | HyperFrames / motion explainers for exec storytelling (not systems of record) |
| Two-way canvases | Eraser-class MCP canvases with human-in-the-loop edits [@eraser-io] |
| Clean rooms | Databricks/Snowflake clean rooms for M&A metadata |

## Guardrails for Mars

- Do not skip Earth/Moon contracts (PAM schema, OPA, Archify types).
- Do not let narrated videos or chat replace the graph.
- Prefer evidence tables (`aliases`, `evidence`) before fancy reasoning.
