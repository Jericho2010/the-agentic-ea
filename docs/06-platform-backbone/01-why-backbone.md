# 5.1 — Why a data+AI platform is the EA backbone

Orbus Infinity can store objects; it cannot economically answer every multi-hop, multi-billion-row question modern EA asks (FinOps amortization, process mining, column lineage audits, model registries).

A **Modern Data and AI Platform**—here, **Databricks** and/or **Snowflake**—becomes the backbone because it provides:

1. Managed ingestion (Auto Loader, Lakeflow Connect, Snowpipe)
2. Governance catalogs (Unity Catalog, Horizon)
3. Orchestration (Workflows/Jobs, Tasks, DLT, Dynamic Tables)
4. AI assistants grounded in enterprise data (Genie Code, Cortex)
5. App surfaces for executives (Databricks Apps, Streamlit in Snowflake)

The backbone stores **PAM facts**. Agents still enforce. Archify still renders.
