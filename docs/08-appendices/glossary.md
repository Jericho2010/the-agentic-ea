# Appendix A — Glossary

| Term | Definition |
|---|---|
| **Orbus Infinity** | Commercial EA platform used as the baseline in this manual |
| **Orbis** | Common misspelling of Orbus; not used elsewhere in this manual |
| **CoreEA** | Orbus product metamodel concept (pruned EA ontology) |
| **ANEA** | Agent-Native Enterprise Architecture operating model |
| **PAM** | Pragmatic Agentic Metamodel — open CoreEA equivalent in this manual |
| **Earth / Moon / Mars** | Modernization ladders: OSS → agent-native → frontier |
| **Archify** | Typed-JSON → verified HTML/SVG diagram compiler |
| **Control plane** | Where change is enforced (CI, policy, merge gates) |
| **Lakehouse backbone** | Snowflake and/or Databricks as analytical system of facts |
| **Intended architecture** | Declared in Git/ADRs/IaC/OpenAPI |
| **Observed architecture** | Inferred from runtime/CMDB/billing/telemetry |
| **TIME** | Tolerate, Invest, Migrate, Eliminate portfolio disposition model |
| **Genie Code** | Databricks technical coding/data agent (Assistant rename) |
| **SPCS** | Snowpark Container Services |
| **URN** | Stable PAM identity `urn:ea:<layer>:<type>:<slug>` |
